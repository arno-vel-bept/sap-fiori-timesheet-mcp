# User flows the tool should enable

## Standard timesheet

As a user, I want:

- To know which days I've already filled in the timesheet, and which are missing
- To edit one or several days & set them to a specific jobcode or absence type
- To know if I my current month contains a specific jobcode, or a set of jobcodes (& their count)
- To toggle the "retrieve staffing" option
- To enable quick actions like "fill the entire open period with jobcode XXX", "fill the entire open period with admin code 0077",


## Multi-project timesheet

As a user, I want:

- To be able to set multiple jobcodes for given days, or for a given date-range (e.g. for every day declare 2 hours on code XXX, 6 hours on code YYY)
- To know what jobcodes are present in a day, date-range, or in the overall open period, & their proportion
- To edit days or date ranges to match an overall proportion (e.g. "during the first two weeks, I want 60% code XXX, 40% code YYY")
